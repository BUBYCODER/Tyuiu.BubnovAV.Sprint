# Tyuiu.BubnovAV.Sprint

Бубнов Андрей. Решения Sprint0–Sprint3 на C#.

- Sprint0: массивы, основы ООП, SOLID, индивидуальный проект.
- Sprint1: устройство классов, свойства, конструкторы и взаимодействие объектов.
- Sprint2: простое и сложное наследование, абстрактный класс, реализация нескольких интерфейсов.
- Sprint3: полиморфизм, переопределение и перегрузка методов, обобщённые классы.
- Индивидуальный проект: вариант 9, «Система заказов товаров и услуг» (Order, OnlineOrder, PhysicalOrder, SpecializedOrder).

Откройте `.ipynb` в VS Code с расширением Polyglot Notebooks и ядром C# (.NET). Запускайте ячейки сверху вниз. Примеры изолированы во вложенных классах, чтобы одинаковые имена Animal и Vehicle не конфликтовали между упражнениями. Данные заданы в коде, Console.ReadLine не используется.

В Sprint2 и Sprint3 каждый Task0–Task2 содержит рабочий пример Vehicle и решение с Animal, Dog, Cat, Bird. Task3 продолжает вариант 9 из Sprint1. В каждом блокноте собственные имена классов-обёрток. Вывод выполненных решений сохранён в ячейках.

Для запуска консольных проектов установите .NET 8 SDK или более новый SDK с поддержкой net8.0. Откройте `Tyuiu.BubnovAV.Sprints.sln` в Visual Studio и выберите нужный проект запуска. Через терминал, например:

```powershell
dotnet run --project Sprint2/Task3/Tyuiu.BubnovAV.Sprint2.Task3.csproj
dotnet run --project Sprint3/Task3/Tyuiu.BubnovAV.Sprint3.Task3.csproj
```

Код консольных проектов совпадает с решениями в блокнотах. Сторонние библиотеки не используются.

В варианте 9 Order содержит общие данные и закрытый список товаров; сумма вычисляется по текущему содержимому заказа. OnlineOrder реализует интерфейсы оплаты и отслеживания. ExpressOnlineOrder наследуется от OnlineOrder и демонстрирует второй уровень наследования. PhysicalOrder сообщает о возврате только после успешного удаления. SpecializedOrder применяет процентную скидку. В Sprint3 добавлены перегрузки AddItem и CalculateTotal, а также OrderCollection<T> с ограничением where T : Order.

Проверка Sprint2–Sprint3: все консольные программы и каждое решение из ячеек скомпилированы без предупреждений и выполнены с помощью C# компилятора .NET Framework 4.8. Дополнительно проверены суммы, скидки 0/10/100%, отказ от некорректной скидки, повторное удаление, запрет оплаты отменённого заказа и операции с обобщённой коллекцией. Сборка csproj через .NET SDK в этой среде не выполнялась: SDK отсутствует.
